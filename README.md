A Python program that draws a one-page newspaper image summing up the
world news of 20 November 2026: a masthead, a hero photo of the Peace
Palace in The Hague, one lead story and seven further stories, all laid
out on a single 768x1024 page.

## Run it

```bash
python3 main.py
```

The program reads `scene.png` from the same directory and writes
`entry.png` to the directory in `MAKEFUN_OUTPUT_DIR`, or to `/output`
when that variable is not set. It needs no network access and produces
the same bytes on every run.
